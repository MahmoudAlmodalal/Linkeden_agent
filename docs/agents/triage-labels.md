# Triage Labels & Category Vocabulary

## Lifecycle Roles
- `ready-for-agent`: Ticket is specced and ready for agent implementation.
- `ready-for-human`: Ticket requires manual developer action or external credential provisioning.
- `needs-triage`: Newly submitted ticket awaiting categorization.
- `needs-info`: Ticket blocked on external details or user clarification.
- `wontfix`: Out of scope or rejected.

## Category Tags
- `enhancement`: Feature or functional capability.
- `infra`: Docker, network, or container environment.
- `documentation`: Guides, specs, glossary, and ADRs.
- `bug`: Defects or regressions.
